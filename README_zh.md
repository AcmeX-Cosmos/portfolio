# portfolio

> AcmeX 个人作品集 — 机器人视觉算法与 ROS2 系统开发

## 项目简介

AcmeX 个人作品集网站，展示机器人视觉感知与 ROS2 系统架构开发领域的项目成果、技术能力与职业经历。网站采用 Vue 3 + Vite 构建，支持响应式布局与暗色主题。

## 功能特色

- **项目展示**：分类展示机器人视觉、ROS2 系统、仿真等方向的项目作品
- **个人经历**：时间线形式呈现教育背景与职业发展轨迹
- **技能雷达**：可视化展示技术栈与能力维度
- **响应式设计**：适配桌面端与移动端浏览
- **暗色主题**：以深色科技风格呈现，突出视觉冲击力

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/AcmeX/portfolio.git
cd portfolio

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **样式**: 原生 CSS（CSS 自定义属性 / 暗色主题）
- **部署**: GitHub Pages
